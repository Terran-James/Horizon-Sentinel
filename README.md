# Horizon Sentinel

Horizon Sentinel is a Python-based defensive security project designed to help identify suspicious authentication activity in Linux system logs.

## Project Goals

- Parse Linux authentication logs into structured events.
- Detect repeated failed SSH login attempts.
- Identify authentication patterns that may warrant further investigation.
- Produce clear, actionable findings for security analysis.
- Build a foundation for additional defensive security detections.

## Initial Scope

The first version will focus on Linux authentication logs and repeated failed SSH login attempts. Detection logic will be tested against controlled sample logs to verify expected behavior and reduce false positives.

## Technology

- Python
- Linux authentication logs
- Git and GitHub
- Automated testing with Python's `unittest` framework

## Project Status

**In development.** Initial project setup and detection planning are underway.

## Learning Objectives

This project is intended to develop practical skills in Python, log analysis, detection engineering, testing, and security investigation.
